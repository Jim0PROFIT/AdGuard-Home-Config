# Liste de filtres autorisés — AdGuard Home

Ce dépôt contient ma liste personnelle de domaines autorisés pour AdGuard Home.  
Objectif : corriger les faux positifs, débloquer certains services et garder une configuration propre et maîtrisée.

## Contenu

- **allowlist.txt** — Liste des domaines explicitement autorisés.
- **changelog.md** — Notes rapides sur les ajouts/suppressions.
- **sources.md** (optionnel) — Références des listes externes utilisées.

## Utilisation

Dans AdGuard Home → *Settings* → *DNS Allowlist*, ajouter l’URL brute :
https://github.com/Jim0PROFIT/AdGuard-Home-Config/blob/main/adguardhome-allowlist.txt

## Notes

- Liste maintenue pour mon usage personnel.
- Les modifications sont faites au fil des besoins (faux positifs, apps spécifiques).
- Le dépôt est public uniquement pour faciliter la synchronisation.
